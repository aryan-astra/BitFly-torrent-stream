# BitFly README banner

`bitfly-banner.png` was created with the built-in image-generation tool for this
repository. The app's original flat B mark is used separately in the README;
the banner does not replace the application icon.

Visual references:

- [Moss banner](https://github.com/aryan-astra/Moss/blob/f158005b734e367fcb96109d3c5a60ccc2619aed/assets/branding/moss-banner.png): composition, paper texture and illustrated warmth.
- [BitFly cloud artwork](../../qml/assets/sky-clouds.png): the approved blue sky and paper-cloud palette.

Final prompt:

```text
Create an original premium GitHub README hero banner for BitFly, a lightweight native Windows torrent-video streaming app. New composition, not a screenshot or fake app interface. Panoramic 3:1 horizontal banner, composed for a 2100 by 700 canvas.
References: image 1 is the user's Moss README banner, for its carefully composed hand-painted editorial warmth, fine paper grain, confident wordmark hierarchy and charming illustration placement ONLY; do not copy its creature, leaves, desktop or green branding. Image 2 is BitFly's approved sky/cloud background, for the powder blue and ivory paper-cloud brand world.
Art direction: airy blue morning sky with visible sculptural cumulus clouds and subtle cut-paper cloud layers along the bottom; warm sunlight and delicate gouache/paper texture, painterly yet restrained. Distinctive, personal, beautiful open-source desktop software identity. The left half holds a large exquisitely typeset dark charcoal editorial serif wordmark reading exactly "BitFly", with the exact small tagline beneath: "a little less waiting". Give all text ample contrast and safe margins.
On the right, one charming coral-red horseshoe magnet, softly dimensional as a small crafted object, catching a short flowing trail of ivory and powder-blue movie-frame tiles, with one subtle play triangle on a tile. This is a metaphor for bringing movie pieces together for playback; make it coherent and understated, not an exploded tech diagram. Small objects, generous calm space, clouds visible rather than a nearly-white image. Use a little muted coral to echo BitFly's controls. Avoid shiny plastic, generic app-icon blocks, neon colors, chrome, gimmicky 3D typography, extra copy, feature badges, invented UI, mascots, logos or watermarks. Do NOT invent or redraw a B logo; the real flat B logo will appear separately in the README. Only the wordmark and tagline are text. Preserve the sense of handcrafted taste from Moss while making the artwork unmistakably belong to BitFly.
```
